1️⃣ WHICH FILE TO INVOKE WHEN

(This is the thing you keep in your head. Everything else lives on disk.)

You only need to remember four moves.

🟢 DEFAULT MODE (do nothing special)

Invoke nothing.

You are in Discovery Mode.

Use this when:

brainstorming

exploring ideas

sketching components

asking “what if”

This keeps AI flexible and creative.

If you didn’t explicitly invoke a file, you are discovering. That’s fine.

🟡 “I care about this project’s intent”

Invoke:

@PROJECT_GENESIS_V2.md


Use this when:

starting a new feature

making UX decisions

touching SEO, positioning, or architecture

something feels “off” but you can’t name why

Mental shortcut:

“What am I building again?”

Genesis answers that.

🔴 “This needs to be correct”

Invoke:

@HARD_GATES.md


Use this when:

you think something is “done”

you’re refactoring

touching routing, state, build, or infra

before accepting code or moving on

Mental shortcut:

“Would this actually run?”

If yes → pass
If no → stop

🟣 “This would change direction”

Invoke:

@PROPOSE_UPGRADE_FORMAT.md


Use this when:

AI suggests a different stack

you’re tempted to add tooling

you’re about to “improve” something foundational

Mental shortcut:

“Are we changing the rules of the game?”

If yes, slow down on purpose.

🚫 USER_HARD_GATES.md (special case)

You almost never invoke this.

This is for you, when you’re asking:

“Should this exist at all?”

“Why would anyone care?”

“Am I avoiding something?”

Mental shortcut:

“Is this worth my life energy?”
